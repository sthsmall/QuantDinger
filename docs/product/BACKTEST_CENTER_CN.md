# 回测中心使用指南

回测用于验证策略在指定历史数据和执行假设下的行为。它是研究工具，不是未来收益承诺，也不证明实盘连接和交易规则已经可用。

## 运行前

确认以下输入：

- 策略源码和 manifest 是计划测试的版本。
- 市场、标的和数据频率使用规范标识。
- 开始时间为指标和 universe 留出足够预热数据。
- 初始资金、费用、滑点和仓位限制符合预期。
- 基准与策略市场和计价币种可以比较。

## 阅读结果

按以下顺序检查：

1. **数据与状态**：任务成功不等于数据完整。确认首尾时间、bar 数、预热和缺失字段。
2. **执行假设**：查看费用、滑点、流动性和未建模项目。Strategy API V2 当前不模拟 Crypto 资金费用。
3. **风险**：检查最大回撤、波动、集中度和最差阶段。
4. **成交账本**：抽查入场、退出、数量、价格、费用和持仓变化是否符合源码。
5. **基准比较**：同时看绝对收益和相对基准表现。
6. **稳健性**：更换时间区间、参数和市场状态，避免只保留最好的一次结果。

## 常见误判

- 零成交可能来自数据缺失、预热不足或条件无法满足。
- 高频数据通常保留更短，长区间请求不一定可用。
- 杠杆收益不能在未估算资金费和强平风险时直接外推。
- 代币化股票、交易所股票永续和传统证券不是同一种执行产品。
- 历史数据可用不代表对应市场支持实盘。
